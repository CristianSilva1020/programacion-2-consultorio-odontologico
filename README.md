# Consultorio Odontológico

Actividad # 1 Modulo Programación II.

## Descripción

El programa desarrollado nos permite registrar las citas de los clientes de un consultorio odontológico y calcular el valor del servicio de acuerdo con el tipo de cliente y el tipo de atención solicitada.

Los datos registrados para cada cliente son:

- Cédula
- Nombre
- Teléfono
- Tipo de cliente
- Tipo de atención
- Cantidad
- Prioridad de atención
- Fecha de la cita

Además, el programa nos permite registrar varios clientes y almacenar su información en memoria.

## En relación con las funcionalidades

El programa permite:

- Registrar varios clientes.
- Validar el tipo de cliente.
- Validar el tipo de atención.
- Validar la cantidad según el servicio.
- Registrar la prioridad de atención.
- Calcular el valor de la cita.
- Calcular el valor de la atención.
- Calcular el valor total a pagar.
- Calcular el número total de clientes.
- Calcular los ingresos totales recibidos.
- Contar los clientes que solicitan extracción de dientes.
- Ordenar los clientes de mayor a menor según el valor de la atención.
- Buscar un cliente por su número de cédula.

## Lenguaje utilizado

Python

## Ejecución

Para ejecutar el programa desde la terminal:

py main.py
